官方价格页的套餐表里只有按国家/地区划分的机房选项，没有出现 CN2 GIA、AS9929、CMIN2 或任何“中国优化”“三网直连”的标注。它卖的是高频 CPU 和低价，线路部分按普通国际带宽处理。

**没有支付宝。** 官方 FAQ 列出的支付方式是信用卡、借记卡、PayPal、Bitcoin 和 USDt Tron。习惯用支付宝付款的国内用户，这一条就是硬门槛，不必等到结账页才发现。

**备份默认含。** 所有档位带每周异地备份，零成本，不用额外买。付费备份计划是按存储大小另行计费的可选项，基础备份不买也有。

**控制面板能做的事不少。** 监控、防火墙规则（不登录机器就能设）、克隆、子账户、浏览器 VNC、IP 管理与浮动 IP 都在面板里，换 IP 和重新分配 IP 可以直接在面板操作，这对做多站点或故障切换的人有用。

**Windows 的门槛官方没标。** 官方提供 Windows 系统模板，但价格页没有写各档能否安装、最低内存多少。按 Windows Server 本身的内存占用，VM-0.5（512MB）和 VM-0.75（1GB）不现实，2GB 是底线，真要用远程桌面干活动手，4GB 的 VM-2 起步更稳。这是我的判断，不是官方条款，下单前用客服确认一遍更保险。

**退款条款在价格页上找不到。** 官方价格页的 FAQ 没有列出退款期限和手续费，资料里也没有可信的第三方记录。这一项我不替它编，付款前直接问客服退款规则，比事后争执省时间。

**端口带宽未在价格页单列。** 表里给的是月流量额度，端口速率没有逐档标注，第三方测评页面提到的是 1Gbps，但没有官方口径佐证，需要精确带宽的话同样问客服。
